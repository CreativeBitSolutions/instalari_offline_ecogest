# Copii exacte ale surselor

Fișierele din acest folder sunt copii ale documentelor existente la data consolidării.

- `instalari_offline_ecogest`, documente și reguli din repository-ul offline.

Documentele din acest folder nu înlocuiesc fișierele operaționale din repository-urile sursă.
